# 人生風險實驗室 Demo

無建置依賴的 HTML / CSS / JavaScript 原型。開啟 `dist/index.html` 即可遊玩。

保留自由客戶輸入、半年一格、骰子決定事件間隔、隨時調整、死亡或支付失敗結束。逐格結算收支／投資／保費／本金／利息，途中可暫停。紀錄保存在瀏覽器，可匯出 JSON。

## 模型限制

- 事件與報酬使用虛構教學參數，並非校準過的金融或精算模型。
- 股票、債券按每半年情境均值加均勻分布波動；現金與房產不計收益。
- 20格循環，四類事件等量；落點才抽事件。自然死亡每半年另行抽取，100歲為原型壽命上限。
- 生活費逐期依情境通膨提高；扶養人數影響家庭保障估算，起始支出以輸入總額為準。
- 保險為虛構固定保費模型，只保障之後事件；未模擬核保、等待期、商品費用或完整條款。
- 65歲改用退休收入；失業一年後恢復，職業型態影響失業機率。
- 現金不足先賣債券，再賣股票；仍不足則無法支付。房產不自動出售。
- 身故給付獨立列作家屬資源，不加入生前資產。
- 未串接 LLM，未實作正式商品試算、個人目標或同事件不同決策比較。

驗證：`node tests/engine.test.cjs`

本機預覽：`python -m http.server 8765 --bind 127.0.0.1 --directory dist`

## 遊戲版 / VPS

遊戲畫面使用 `game.css` 與 `game.js`：立體棋盤、角色棋子、骰子動畫、事件卡、規劃背包與冒險日誌。所有核心規則仍由 `engine.js` 計算。

- 網址： https://life-game.ntut.org
- 原始碼： `/home/changrun/cardif-life-demo`
- Git remote： `vps:/home/changrun/repos/cardif-life-demo.git`
- systemd user service： `cardif-life-game.service`
- 監聽： `127.0.0.1:8390`
- 日誌： `journalctl --user -u cardif-life-game.service`
- 停止： `systemctl --user stop cardif-life-game.service`
- 更新：筆電 commit 並 push VPS 的 `game-vps` 分支；VPS checkout 執行 `git pull --ff-only` 後 `systemctl --user restart cardif-life-game.service`。

部署設定在 `deploy/`。HTTPS由nginx與Certbot管理；客戶輸入仍只存於瀏覽器。

## V0.2：三欄規劃與投資型保單

- 左欄分頁：總經參數、投資配置、遊戲紀錄；中欄棋盤；右欄保險／生活規劃。手機改成側面板，主畫面維持固定視窗。
- 分類顯示「事件／意外／機遇／人際」。事件立即結算後彈窗並暫停，關閉後才繼續；未讀事件會隨存檔還原。
- 總經採教學情境：通膨、政策利率、浮動貸款與存款利率、GDP、失業率、股債報酬中心。GDP與失業率作為情境指標；失業事件仍由情境倍數抽樣。GDP不是獨立估計模型。情境屆滿，政策與貸款利率回到基準。
- 新增獨立教學投資型壽險：每筆投入扣3%，每月管理100元，帳戶年費0.8%、基金年費0.6%，月扣年齡／健康／淨危險保額相關成本。身故給付取100萬元保額與帳戶價值較大者，不重複計入遺產。
- 解約與部分提領依第1–5保單年收6%／5%／4%／3%／2%，第6年起0%。部分提領後至少保留1萬元。每保單年12次免費配置轉換，第13次起每次500元。
- 支援投保、追加、部分提領、全部解約、配置調整、續繳暫停與恢復；交易前顯示扣費及實領預覽。每半年逐月模擬6次扣費。現金不足跳過續繳；帳戶耗盡失效。一般資產用盡後，最後強制解約，仍不夠才支付失敗。
- 投資型投入、投資損益與費用各自記帳；不把全部保費當成支出損失。仍未模擬核保、稅務、外幣、借款、交易等待、催告寬限期或年金化。

以上是自訂教學契約，**不是法巴正式商品費率或試算**。費用類型參考[法巴公開投資型商品說明](https://life.cardif.com.tw/zh/p85)；正式商品應逐項取得核准條款與費率表後另建模型。
